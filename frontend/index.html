Key terms
Defender
The patrol. It commits to a probability distribution over routes.
Attacker
An intruder who observes that distribution and picks the most profitable target.
Target
A checkpoint with an asset value, a reward if breached and a penalty if caught.
SSE
Strong Stackelberg Equilibrium: the defender's best commitment when the attacker best-responds and breaks ties in the defender's favour.
Entropy
Normalized Shannon entropy of the route distribution. 0 is a fixed schedule, 1 is uniform.

Insights and recommendation

What each policy trades away, and which one the benchmark supports.

  • Fixed schedule

    Always runs the same route, so entropy is zero. An observer knows exactly which checkpoints go unwatched and attacks one of them with no risk.

  • Uniform random

    Gives every route equal probability, which maximizes entropy. It also guards a low-value corridor as often as the server room.

  • Stackelberg patrol

    Solves for the commitment the attacker can best respond to least profitably. Coverage concentrates where an attack would otherwise pay most.

Security Insights

1. Fixed Schedule Patrol:

Repeatedly uses the same patrol route, making it highly predictable (0 entropy). An intelligent intruder can observe this pattern and attack unpatrolled high-value locations with zero detection risk.

2. Uniform Random Patrol:

Assigns equal probability to all feasible strategies. While this maximizes route unpredictability (maximum entropy), it treats high-value targets identically to low-value targets.

3. Game-Theoretic Patrol:

Uses Stackelberg Security Game linear programming optimization to account for target valuations and intruder responses, achieving optimal randomized resource allocation.

OPTIMAL SELECTION

Game-Theoretic Stackelberg Patrol

Based on empirical multi-experiment simulation, the Game-Theoretic policy is recommended as it optimizes target coverage against adaptive attackers, providing superior defender utility compared to naive baseline strategies.

Performance Trade-offs:
  • High Security Payoff: Maximizes expected defender utility by protecting high-value targets.
  • Adaptive Unpredictability: Strategic randomization prevents intruder exploitation without blindly wasting patrol effort on low-value areas.

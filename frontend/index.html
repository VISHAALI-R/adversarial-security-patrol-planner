Game-Theoretic Security Analysis

THEORETICAL FRAMEWORK
1. Fixed Schedule Patrol (Zero Entropy):

Repeatedly follows a deterministic route ($H = 0$). An observant adversary can exploit this static schedule with 100% certainty, targeting undefended checkpoints at zero risk.

2. Uniform Random Patrol (Maximum Entropy):

Spreads probabilities equally across all feasible routes. While maximizing schedule unpredictability, it blindly treats low-value corridors with equal priority to critical infrastructure.

3. Game-Theoretic Stackelberg Patrol (Equilibrium Solution):

Formulates the security interaction as a Stackelberg game. By solving Multiple Linear Programs, it allocates randomized coverage precisely weighted by asset values and anticipated attacker best responses.
